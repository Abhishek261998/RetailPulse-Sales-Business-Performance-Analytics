# Excel Task Performed:-

1. Open `Data/Sales_Data.xlsx`.
2. Convert the Sales_Data range to an Excel Table.
3. Verify:
   - Order_ID uniqueness
   - Order_Date is a valid date
   - Quantity > 0
   - Sales >= 0
   - Cost >= 0
   - Profit = Sales - Cost
4. Create PivotTables for:
   - Monthly Sales
   - Monthly Profit
   - Sales by Region
   - Sales by Category
   - Top 10 Products
   - Top 10 Customers
   - Sales Channel
   - Payment Mode
   - Returns
5. Created an Excel dashboard with KPI cards and charts.
6. Save the cleaned workbook separately as `Cleaned_Sales_Data.xlsx`.
